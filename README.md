# Золотой Лотос — интернет-магазин

**Выбран вариант v11 «Туман над горами».** Пакет для переноса в Тильду и инструкция — в папке [`tilda/`](tilda/ИНСТРУКЦИЯ.md).
Страницы документов: [`privacy/`](privacy/) (политика конфиденциальности) и [`soglasie/`](soglasie/) (согласие на обработку ПД).

Интернет-магазин товаров для здоровья и красоты из Таиланда, Китая и Южной Кореи.
Самовывоз: Южно-Сахалинск, пр. Мира, 229, рынок «Янтарь», место 2А.

Прототипы на чистом HTML/CSS/JS, потом выбранный вариант переносится в Тильду.

| Вариант | Стиль | Шрифты |
|---|---|---|
| [v9](v9/) | Закат — фото храма, тёплое золото | Pattaya + Nunito |
| [v10](v10/) | Орхидея — белый и розовый, фото в арках | Yeseva One + Golos Text |
| [v11](v11/) | Туман над горами — шалфейный зелёный | Prata + Manrope |

## Устройство
Хаб — `index.html`. Общий код в `lite/`: `products.js` (категории, подкатегории, товары, поле `with` — что рекомендовать к товару, настройки магазина: телефон, мессенджеры, часы), `shop.js` (каталог, карточка с «С этим берут», корзина, заказ на самовывоз без оплаты), `shop.css`. Без GSAP и 3D.
Телефон, мессенджеры и часы работы в `lite/products.js` — заглушки, заменить.

## Перенос в Тильду
Пошагово — [`tilda/ИНСТРУКЦИЯ.md`](tilda/ИНСТРУКЦИЯ.md). Коротко: статичные блоки — T123 из `tilda/0*.html`, товары — каталог Тильды (`tilda/tovary-dlya-importa.csv`), корзина — ST100, заказы — Telegram + почта + «Заявки» + Tilda CRM.
