# Золотой Лотос — 5 вариантов дизайна главной страницы

Интернет-магазин товаров для здоровья и красоты из Таиланда, Китая и Южной Кореи.
Самовывоз: Южно-Сахалинск, пр. Мира, 229, ТЦ «Янтарь», место 2А.

Прототипы на чистом HTML/CSS/JS, потом выбранный вариант переносится в Тильду.

| Вариант | Стиль | Шрифты |
|---|---|---|
| [v1](v1/) | Золотой храм — тёмный изумруд и золото | Cormorant Garamond + Manrope |
| [v2](v2/) | Цветущая орхидея — светлая пастель | Pattaya + Nunito |
| [v3](v3/) | Шёлковый путь — журнальная вёрстка | Playfair Display + Golos Text |
| [v4](v4/) | Тропический закат — яркие градиенты, стекло | Unbounded + Onest |
| [v5](v5/) | Дзен-сад — минимализм, туман | Forum + Mulish |

## Что общее
- `shared/products.js` — демо-товары и настройки магазина (адрес, доставка, скидки, промокоды).
- `shared/shop.js` / `shop.css` — каталог с фильтрами, корзина-калькулятор, оформление, демо-оплата, бот-помощник, меню.
- `shared/fx.js` — анимации (GSAP + ScrollTrigger, плавный скролл Lenis).

## Перенос в Тильду
- Каталог → Tilda Store / блоки карточек ST.
- Корзина и калькулятор → штатная корзина ST100 (скидки, промокоды, доставка настраиваются в ней).
- Оплата → платёжная система в настройках сайта (ЮKassa, Т-Банк, CloudPayments).
- Анимации первого экрана → Zero Block (пошаговые анимации) или блок T123 со своим кодом.
- Бот → виджет Telegram/WhatsApp или блок T123.
