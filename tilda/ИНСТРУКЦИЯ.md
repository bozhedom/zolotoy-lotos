## Шаг 1. Настройки сайта (один раз)

**Настройки сайта → раздел со шрифтами** (может называться «Шрифты» или «Шрифты и цвета»)
- Шрифт заголовков **Prata** и шрифт текста **Manrope**. Для воспроизводимого оформления файлы шрифтов уже подготовлены в WOFF/WOFF2 и лежат в папке **`shrifty/`**:
  1. **Загрузить свой шрифт.**
  2. Название шрифта: **`Prata`**, ровно так, с большой буквы: блоки T123 ищут шрифт по этому имени. Начертание **Regular (400)**: в поле WOFF — `Prata-400.woff`, в поле WOFF2 — `Prata-400.woff2`.
  3. Второй шрифт, название **`Manrope`**. Четыре начертания, в каждое по паре файлов:
     | Начертание | WOFF | WOFF2 |
     |---|---|---|
     | Regular 400 | `Manrope-400.woff` | `Manrope-400.woff2` |
     | Medium 500 | `Manrope-500.woff` | `Manrope-500.woff2` |
     | Semibold 600 | `Manrope-600.woff` | `Manrope-600.woff2` |
     | Bold 700 | `Manrope-700.woff` | `Manrope-700.woff2` |
     Кнопку «вариативный шрифт» не используйте — загружайте обычные файлы по начертаниям.
  4. Выберите: шрифт заголовков — **Prata**, шрифт текста — **Manrope**. Сохраните.
  
  Шрифты бесплатные, по лицензии OFL их можно использовать на коммерческом сайте (лицензии лежат в той же папке). Ссылку `<link>` на Google Fonts в код **не вставляйте**: иначе данные посетителей уходят в Google, а это лишний вопрос по 152-ФЗ.
  Блоки T123 своих шрифтов не подключают, они берут шрифты сайта. Если шрифты не загрузить или назвать иначе, всё покажется в Georgia и Arial. Проверка: после публикации заголовок «Товары для здоровья…» должен быть с засечками, как на макете.
- **Цвета в настройках сайта не задаются**: общего поля «цвет кнопок / цвет текста» в Тильде нет.
  - Блоки из этой папки (шапка, главный экран, самовывоз, контакты, документы) уже покрашены в коде, в них ничего настраивать не нужно. Фон всей страницы `#f4f5f0` задаёт код шапки (на страницах документов — их собственный код).

## Шаг 4. Каталог товаров (то, что заказчица правит сама)

1. Откройте сайт «Золотой Лотос» → **«Настройки сайта» → «Подключаемые модули» → «Каталог товаров» → «Подключить»**, затем **«Начать работу с каталогом»**. Если каталог уже подключён, откройте его для редактирования товаров. Это панель управления товарами; блок с карточками добавляется на страницу отдельно, в шаге 5. [Инструкция Тильды по подключению каталога](https://help-ru.tilda.cc/online-store/catalog).
2. Создайте **разделы** (категории): «Разделы» → «Добавить раздел».
   `Уход за лицом` · `Тело и баня` · `Волосы` · `Здоровье` · `Чай и травы`
3. Создайте **подразделы**: в «Разделах» нажмите **«+» рядом с разделом** (вложенность — до 10 уровней):
   - Уход за лицом → `Маски`, `Сыворотки`, `Кремы`, `Очищение`
   - Тело и баня → `Мыло`, `Масла`, `Скрабы`, `Полотенца и мочалки`
   - Волосы → `Шампуни`, `Маски и масла`
   - Здоровье → `Бальзамы`, `Пластыри`, `Ингаляторы`
   - Чай и травы → `Чай`, `Травяные сборы`

   Создайте **характеристики** `Страна` и `Объём` (их видно в карточке товара, по стране можно сделать фильтр).
4. **Импорт:** «Импорт» → CSV → файл `tovary-dlya-importa.csv` → проверьте, что колонки сопоставились (Title → Название, Category → Раздел, Price → Цена, Mark → Отметка, Characteristics:… → характеристики).
   Если раздел не подтянулся сам — выберите его у товаров вручную.
   **Разложить по подразделам:** CSV кладёт товар только в раздел. Выделите галочками товары → «Действия» → «Переместить в раздел» → выберите подраздел. Подсказка, куда что класть, — колонка `Characteristics:Вид` в CSV (её можно не импортировать).
   Это **демо-товары**: на них видно, как всё работает. Потом заказчица их заменит или удалит.
5. **«С этим берут».** В карточке товара есть блок связанных товаров («Связанные товары» / «См. также»). Заполните по таблице в конце этого файла. Заголовок блока на сайте: `С этим берут`.

> Фото товаров заказчица добавляет сама. Лучше квадратные, на светлом фоне, от 1000×1000.

Это блок из категории «Магазин» для вывода товаров из каталога сайта. [Анонс ST340 от марта 2026 года](https://blog.tilda.cc/tpost/1hpglxj5v1-novii-blok-st340-universalnii-blok-kata), [актуальная инструкция Тильды](https://help-ru.tilda.cc/online-store/catalog).

3. В поиске **библиотеки блоков** введите **`ST340`** латинскими буквами. Можно скопировать номер из этой инструкции.
4. Нажмите на найденный блок, чтобы добавить его на страницу. Другой путь: в левой колонке библиотеки выберите **«Магазин»** и найдите карточку **ST340** с названием про каталог товаров и отметкой **Catalog**.

**Как подключить свои товары:**

1. У добавленного **ST340** нажмите **«Контент»**.
2. В поле **«Выводить товар из каталога»** выберите нужный раздел или все товары для общей витрины. Если каталог ещё не подключён, выполните первый пункт шага 4.
3. Сохраните изменения и опубликуйте страницу. В блоке должны появиться товары из выбранных разделов. [Как вывести разделы каталога в блоке](https://help-ru.tilda.cc/online-store/catalog/category).

**Если поиск по номеру пустой:** очистите строку поиска, откройте категорию **«Магазин»** и найдите блок по названию **«Каталог товаров»** с отметкой **Catalog**. Для вывода каталога текущая справка Тильды указывает ST340 и его вариации. Если и такого блока нет, нужен скриншот открытой библиотеки, чтобы уточнить путь по вашему интерфейсу. Если блок уже добавлен, но товары не появились, проверьте подключение каталога, выбранный раздел и наличие в нём видимых товаров.

**Настройки блока:**

- картинка: соотношение 5:4 или 1:1, **вписать** (не обрезать), фон картинки `#e9eee6`;

Включите **поиск** с подсказкой `Найти: маска, бальзам, чай…`. [Настройка фильтров в Тильде](https://help-ru.tilda.cc/online-store/filters);
- в подробной карточке товара: показывать характеристики и **связанные товары**.

Расположение разделов и карточек задавайте штатными настройками ST340. После публикации проверьте выравнивание на компьютере и телефоне.
